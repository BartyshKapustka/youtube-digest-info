YouTube Digest

A personal tool operated by Egor Tulyakov that prepares Russian-language digests from videos published by his subscribed YouTube channels.

What the tool does

  1. Reads the authorized account’s YouTube channel subscriptions using the YouTube Data API.
  2. Finds recent public videos and checks their duration and category. Short videos and music are filtered out.
  3. Uses Apify to retrieve available transcripts for selected public videos.
  4. Stores collected material in a private GitHub repository. A scheduled ChatGPT task reads selected transcripts and prepares the digest.

Google account access

The tool requests https://www.googleapis.com/auth/youtube.readonly. Its current code uses that permission to read subscriptions and video metadata. It does not post comments, upload videos, or change subscriptions. The Google account password is never collected by this application.

Personal use

This application is intended for the operator’s own account. This website provides project and privacy information; it does not offer public registration or request Google sign-in.
